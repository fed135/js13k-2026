# JS13KGames Submission: 


Full source in the `src` folder.

## To launch from source:

```
npm run start
```

## To build the compressed version:


```
npm run build
```

Outputs a `minified` .zip archive


```
npm run publish
```

Uploads the build to [Wavedash](https://wavedash.com/dev-portal/fed135)
